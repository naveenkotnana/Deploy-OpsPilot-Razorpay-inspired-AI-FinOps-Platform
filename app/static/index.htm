System Architecture & Implementation Design

Designed for reliability, transparency, local execution, and auditability.

🧠 Local LLM Inference

Ollama runs qwen2.5:3b-instruct locally on your host. Absolutely no external API calls, zero credit card bills, and full offline privacy.

⚡ LangGraph Deterministic Graph

Single stateful 10-node graph. Replaced brittle multi-agent architectures with hard stops at human approval gates for critical actions.

📚 In-Process RAG Vector Store

TF-IDF + Cosine index with exact citation tracking. Compact footprint (~230 lines of policy), saving memory on 8 GB systems.

🔒 RBAC & Security

Hierarchical token-based clearance: Analyst (read & investigate), Manager (approve/reject & execute), Admin (system-wide config).

📈 SQL Analytics Engine

11 pre-compiled analytical queries with window functions (SUM OVER, AVG OVER), protecting against injection and divide-by-zero.

🧪 65/65 Verified Unit & Integration Tests

Automated test suite validates pipeline integrity, RAG retrieval scores (1.000), agent precision, and SQL mathematical exactness.
